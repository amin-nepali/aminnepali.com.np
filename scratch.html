Scratch Programming – Grade 7

Textbook Exercise Answers

1. Short Answer Questions

a. What is the default sprite in Scratch?
Orange Cat
b. List the different code blocks in Scratch.
Motion, Looks, Sound, Events, Control, Sensing, Operators, Variables, My Blocks
c. Write any two features of Scratch programming.
Easy to use; Visual block coding (drag-and-drop); No syntax errors; Interactive
d. Which block would you use if you have to repeat any action 10 times?
Repeat block
e. What is the other name for background in Scratch?
Backdrop
f. List any 4 components of Scratch interface.
Stage, Sprite List, Blocks Palette, Script Area
g. Which block is visited if you want to check the condition?
If block

2. Long Answer Questions

a. Discuss the various features of Scratch.
Visual block-based coding; Beginner-friendly; Interactive animations and games; Large library of sprites and backdrops; No syntax errors.
b. "Scratch is the best programming tool for learners." Explain.
Simple drag-and-drop interface; Encourages logical thinking and creativity; Error-free syntax; Instant visual feedback.
c. Define stage area in Scratch.
The part of Scratch where sprites perform actions; the visual display area of the project.
d. What is a sprite in Scratch? Why is it an important element for coding?
A sprite is a character/object that performs actions; important because they are the main actors in a project.
e. Discuss the use of code area available in Scratch.
The code area is where we arrange blocks to create scripts that control sprites.
f. If you need to change the background of the stage, which option would you choose? Discuss.
Use Choose a Backdrop; you can select from the library, paint, or upload your own image.
g. In Scratch, what is the role of a sprite, and how does it interact with the project?
Sprites perform the programmed actions and interact with the stage, backdrops, and other sprites.
h. How can you move a sprite across the stage in Scratch?
Use Motion blocks such as Move steps, Go to x,y, or Glide to. Example: When Green Flag Clicked → Move 10 steps.

3. Additional Questions from First Image

i. If you want to make a sprite perform an action multiple times, which block would you use, and how does it work?
Use the Repeat block (fixed number of times) or Forever block (repeats endlessly) to repeat actions.
j. What is the function of the "When Green Flag Clicked" block?
It starts the program when the green flag is clicked. Commonly used as a standard starting point for Scratch projects.
k. Explain how you can add and change the backdrop in a Scratch project.
1. Click Choose a Backdrop in the Stage area.
2. Select from library, paint, or upload.
3. Customize using the Backdrop Editor tools.

Scratch Programming – Grade 7

Textbook Exercise Answers

From First Image

i. If you want to make a sprite perform an action multiple times...
Use the Repeat block (for fixed times) or Forever block (endless repetition). The block repeats the set of actions placed inside it.
j. Function of "When Green Flag Clicked" block...
It starts the program when the green flag is clicked. It is commonly used because it provides a standard way to begin projects.
k. Adding and changing the backdrop...
Steps:
1. Click Choose a Backdrop in the Stage area.
2. Select from the Scratch library, paint, or upload an image.
3. Customize it using the Backdrop Editor tools.
